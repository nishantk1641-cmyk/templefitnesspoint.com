TEMPLE FITNESS POINT GYM — WEBSITE DEMO

Files:
- index.html — complete responsive website

How to use:
1. Extract the ZIP.
2. Open index.html in a browser, or open it in Acode/Treb Editor.
3. Replace the demo gallery images with the gym's own photos before selling/publishing.
4. Confirm phone number, hours, services, ratings and membership information with the owner.

The page is designed as a sales-ready prototype with:
- Responsive mobile/desktop layout
- Hero section
- Services/programs
- Gallery
- Google Maps directions button
- Call + WhatsApp buttons
- Modern dark + lime fitness theme
